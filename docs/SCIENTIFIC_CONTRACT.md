# Current result identity

This package accompanies *Different DNA Variants, Same Amino Acid Substitution: A MaveDB Analysis Including the Pancreatic Cancer Susceptibility Gene BRCA2* (software release v1.0.0). It excludes
obsolete drafts, internal simulated-review correspondence and operational logs.
No manuscript text is regenerated by the analysis code.

- BRCA2 primary Phi: 0.8750878921486126 = **87.51%**; ordinary group-bootstrap
  95% CI 76.80–98.66%. The 87.59% class-control missense result is a separate
  remapping/z-scoring sensitivity, never the primary estimate.
- BRCA2: 823 shared nucleotide identifiers, 388 same-amino-acid groups,
  367 protein positions; concordance 193/388 = 49.74%. There are 341 groups
  of two (171 concordant) and 47 groups of three (22 concordant). Primary R
  position-cluster interval: 44.79–54.76%. Wilson interval: 44.79–54.70%.
- Fractional-rank sensitivity: average rank within all mapped missense rows
  of each source, divided by that source's row count; Phi = 95.985%.
- MSH2 primary endpoint: reconstructed **6-TG/mock** count ratio; relative
  RMSE gains 4.18%, 4.48%, 4.20% in held replicates 1, 2, 3. Cohorts have
  (DNA keys, AA groups, positions) = (24619,8547,887), (23997,8416,900),
  (24156,8474,892). Source AA means and same-DNA residuals are available at
  evaluated positions; only beta is position-cross-fitted. This is transfer
  between related culture replicates sharing a starting pool and WT reference,
  not validation in unseen positions, unseen DNA keys or independent studies.
- MSH2 primary intervals use 5,000 position-bootstrap draws with beta refitted
  in every fold and draw. DB6/P0 and mock/P0 remain separately named endpoints.
- Collection: frozen manifest 92 score sets, 89 analyzable, 413090 numeric
  missense rows; 31723 historical keys in 13041 groups from 27 score sets.
  3836 reference-qualified **and source-scored** groups / 19 sets is an
  intersection, not the whole source-score universe. Narrow versioned-request
  tier: 2679 groups / 13 sets; conditional target tier: 1013 / 7 sets.
- Splicing: 22 prespecified pairs, technical coverage/overlap audit only.
  Event, transcript, strand and condition harmonization is unresolved; no
  biological validation or correlation/p-value interpretation is claimed.
- ClinVar: 53 identifiers in the original snapshot versus 34 current ESummary
  records use different fields and dates; these are coverage observations.

Removed predictive comparisons, same-alpha power claims and an unverified
